# ⏳ Eisenhower Life Manager

เว็บแอปจัดการงานและชีวิตประจำวัน สร้างจาก Eisenhower Matrix พร้อมปฏิทินความคืบหน้า, ตัวจับเวลากิจกรรม, ระบบเป้าหมายแบบมีระดับสี, สถิติแนวโน้ม และการเตือนความจำตามเวลา/สถานที่

ตัวแอปหลักทำงานบนเบราว์เซอร์ล้วนๆ ข้อมูลงาน ปฏิทิน การจับเวลา เป้าหมาย และการเตือนความจำ ถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์ผู้ใช้เอง ไม่ต้องมีเซิร์ฟเวอร์
ส่วนแบบประเมิน (Feedback) สำหรับเก็บผลสะท้อนจากกลุ่มทดลองเป็นข้อยกเว้น: คำตอบทุกชุดจะถูกส่งไปบันทึกใน **Google Sheet** ผ่าน Google Apps Script ซึ่งทำหน้าที่เป็นฐานข้อมูลกลางของระบบ ไม่ต้องรันเซิร์ฟเวอร์เอง ดูวิธีตั้งค่าได้ในหัวข้อ "ฐานข้อมูล Feedback" ด้านล่าง

## ✨ ฟีเจอร์

### 🧭 วันนี้
สรุปภาพรวมของวัน — งานที่เลยกำหนด, งานที่ครบกำหนดวันนี้, เรื่องเล็กๆ ที่ต้องเตือน, ตัวเลขสรุป (เวลาโฟกัสวันนี้เทียบเมื่อวาน, งานที่ปิดได้สัปดาห์นี้, จำนวนวันที่ทำต่อเนื่อง), แถบความคืบหน้าของทุกเป้าหมาย และไทม์ไลน์รวมทุกอย่างเรียงตามเวลา

### 📊 งานทั้งหมด (Eisenhower Matrix)
เพิ่มงานพร้อม **คำอธิบาย** และกำหนดส่ง ระบบจะจัดเข้า 4 ช่องตามความสำคัญ/ความเร่งด่วน

- 🚨 Q1 ทำทันที
- 📅 Q2 วางแผนทำ
- 👥 Q3 ให้คนอื่นทำแทน
- 🗑️ Q4 ทำท้ายสุด

คลิกที่ชื่องานเพื่อเปิดหน้ารายละเอียด แก้คำอธิบาย ปรับเปอร์เซ็นต์ความคืบหน้าด้วยแถบเลื่อน ดูเวลาที่ใช้ไปกับงานนั้น หรือกดจับเวลาทำงานนั้นได้ทันที ถ้าพิมพ์ชื่องานผิด กดปุ่ม ✎ บนการ์ดเพื่อเปิดหน้ารายละเอียดพร้อมโฟกัสไปที่ช่องชื่อทันที แก้แล้วกด "บันทึกชื่อ"

งานที่ทำเสร็จแล้วจะถูกเลื่อนลงไปอยู่ล่างสุดของช่องโดยอัตโนมัติ ส่วนงานที่ยังค้างเรียงตามกำหนดส่งจากใกล้ที่สุดไปไกลที่สุด ทำให้งานที่ต้องสนใจอยู่บนสุดเสมอ

### 📅 ปฏิทิน
ดูงานแบบรายเดือน แต่ละวันแสดง **แถบสีความคืบหน้าเฉลี่ย** ของงานที่ครบกำหนดวันนั้น จุดสีบอกควอดแรนต์ของงาน และจุดน้ำเงินบอกวันที่มีการจับเวลา คลิกวันไหนก็เห็นสรุปและรายการงานของวันนั้น พร้อมปุ่มเพิ่มงานให้ตรงวัน

### ⏱️ จับเวลากิจกรรม
นาฬิกาจับเวลาแยกต่างหากสำหรับกิจกรรมอย่างอ่านหนังสือ ทำงาน เรียน หรือออกกำลังกาย เลือกกิจกรรม ผูกกับงานในเมทริกซ์ได้ (ถ้าต้องการ) ใส่บันทึกสั้นๆ แล้วกดเริ่ม/จบ เวลาจะถูกเก็บเข้าสถิติและนับเข้าเป้าหมายอัตโนมัติ มีปุ่มบันทึกเวลาย้อนหลังเผื่อลืมกดจับเวลา

### 🎯 เป้าหมาย
ตั้งเป้าเวลาต่อวัน/สัปดาห์/เดือน สำหรับแต่ละกิจกรรม แล้วระบบจะนับความคืบหน้าจากการจับเวลาให้เอง แต่ละเป้าหมายจะเลื่อน **ระดับตามสี** ตามเปอร์เซ็นต์ที่ทำได้

| ระดับ | ช่วง | สี |
|---|---|---|
| ยังไม่เริ่ม | 0% | เทา |
| เริ่มแล้ว | 1–39% | เหลือง |
| ไปได้ครึ่งทาง | 40–69% | ฟ้า |
| ใกล้เสร็จ | 70–99% | น้ำเงิน |
| สำเร็จแล้ว | 100% | เขียว |

ระดับสีชุดเดียวกันนี้ใช้กับความคืบหน้าของงานในเมทริกซ์และในปฏิทินด้วย

### 📈 สถิติ
- กราฟแท่งแนวโน้มเวลาโฟกัสรายวัน (เลือกดู 7 / 14 / 30 วัน) พร้อมเส้นค่าเฉลี่ยเคลื่อนที่ 3 วันเพื่อดูทิศทาง
- เวลารวมและเฉลี่ยต่อวัน เทียบกับ 7 วันก่อนหน้าว่าเพิ่มขึ้นหรือลดลง
- อัตราส่งงานทันกำหนด
- ความคืบหน้าเฉลี่ยของงานที่ยังค้าง
- จำนวนงานที่ปิดได้ในแต่ละสัปดาห์ย้อนหลัง 6 สัปดาห์
- สัดส่วนเวลาแยกตามกิจกรรม

### 🔔 เตือนความจำ
บันทึกเรื่องเล็กๆ เช่น กินยา โทรกลับแฟน ทิ้งขยะ พร้อมตั้งเตือนได้ 3 แบบ

- ⏰ ทุกวันตามเวลาที่กำหนด
- 📆 ครั้งเดียวตามวัน-เวลาที่กำหนด
- 📍 เมื่อไปถึงสถานที่ที่กำหนด (กำหนดรัศมีเป็นเมตรได้)

## 🚀 วิธีเปิดใช้งาน

ไม่ต้องติดตั้งอะไรและไม่ต้อง build เลือกวิธีใดวิธีหนึ่ง

- **Live Server ใน VS Code**: คลิกขวาที่ `index.html` แล้วเลือก Open with Live Server
- **เทอร์มินัล**: เปิดในโฟลเดอร์นี้แล้วรัน `npx serve .` (หรือ `python -m http.server 8000`) จากนั้นเปิดลิงก์ที่แสดง
- **ให้คนอื่นใช้ได้**: อัปโหลด `index.html`, `style.css`, `script.js` ขึ้น GitHub Pages หรือ Netlify

แนะนำให้เปิดผ่าน `localhost` หรือ `https` (สองวิธีแรกและวิธีสุดท้าย) เพราะการแจ้งเตือนและการระบุตำแหน่งของเบราว์เซอร์บางตัวไม่ทำงานเมื่อดับเบิลคลิกเปิดไฟล์ตรงๆ

ก่อนแจกให้กลุ่มทดลอง ต้องตั้งค่า Google Sheet ตามหัวข้อ "ฐานข้อมูล Feedback" และใส่ลิงก์ที่ตัวแปร `FEEDBACK_URL` ใน `script.js`

## 🛠️ Tech Stack

- HTML5 + CSS ที่เขียนเอง ไม่พึ่ง framework และไม่ต้อง build

### 🗳️ แบบประเมิน (เก็บ Feedback จากกลุ่มทดลองลงฐานข้อมูล)

หน้าสำหรับเก็บผลสะท้อนหลังการใช้งาน ออกแบบมาให้ใช้กับการทดลองในรายวิชาโดยเฉพาะ **หน้านี้แสดงเฉพาะฟอร์ม ไม่มีการแสดงผลสรุปหรือคำตอบของใครกลับบนหน้าเว็บเลย** — ส่งแล้วข้อมูลจะไปอยู่ใน Google Sheet ของผู้วิจัยทันที ผู้ทดลองใช้จะเห็นแค่ข้อความ "ส่งคำตอบเรียบร้อย"

เปิดหน้านี้ด้วยปุ่ม 🗳️ เล็กๆ ที่มุมขวาบนของหัวเว็บ (ไม่มีในแถบแท็บ) ปุ่มนี้กดแล้วสลับไปที่หน้าประเมินผล และกลับมาใช้งานปกติได้โดยกดแท็บใดก็ได้

**แบบประเมิน** ประกอบด้วย

- ระยะเวลาที่ได้ใช้งาน และช่องกรอกที่มีชือ่ในฟอร์ม ระบบจะบันทึกรหัส/ชื่อผู้ตอบด้วย ถ้าไม่มีจะบันทึกว่า "ไม่ระบุ"
- คำถามมาตรวัด 1–5 จำนวน 6 ข้อ ครอบคลุมการจัดลำดับงาน การลืมงาน การวางแผนล่วงหน้า การโฟกัส การเห็นพฤติกรรมตัวเอง และความง่ายในการใช้งาน
- แถบเลื่อน 0–100% ว่าโดยรวมเว็บนี้ช่วยแก้ปัญหาได้มากแค่ไหน
- คะแนนแนะนำต่อ 0–10 (ใช้คำนวณ NPS ได้ภายหลัง)
- ฟีเจอร์ที่ช่วยได้มากที่สุด (เลือกได้หลายข้อ)
- ปัญหาที่เจอ และข้อเสนอแนะแบบข้อความ

แก้ไขชุดคำถามได้ที่ตัวแปร `LIKERT_QUESTIONS` และ `FEATURE_OPTIONS` ตอนต้นส่วน FEEDBACK ใน `script.js` เพิ่มหรือลดข้อได้ตามสมมติฐานการทดลอง

## 🗄️ ฐานข้อมูล Feedback (Google Sheet + Apps Script)

เมื่อผู้ทดลองใช้กด **"ส่งแบบประเมิน"** หน้าเว็บจะส่งคำตอบแบบ `POST` (JSON) ไปที่ Google Apps Script Web App ซึ่งเขียนคำตอบต่อท้ายชีตชื่อ `feedback` ใน Google Sheet ทันที Sheet นี้คือฐานข้อมูลของระบบตามที่โจทย์ของรายวิชาต้องการ

**คุณสมบัติสำคัญ**

- คำตอบไม่ถูกแสดงกลับบนหน้าเว็บที่ไหนเลย ไม่มีหน้าสรุปผล ไม่มีรายการคำตอบให้ผู้ทดลองใช้เห็น ลิงก์ Web App รับได้เฉพาะการส่งข้อมูลเข้า (`doPost`) ไม่มีฟังก์ชันอ่านข้อมูลกลับ
- ถ้าส่งไม่สำเร็จ (เช่น อินเทอร์เน็ตหลุด) ระบบจะเก็บคำตอบไว้ชั่วคราวใน `localStorage` ของเครื่องนั้น แล้วพยายามส่งซ้ำให้อัตโนมัติทุก 2 นาที โดยไม่แสดงผลใดๆ บนหน้าเว็บเช่นกัน
- หน้าเว็บใช้ `mode: 'no-cors'` เพราะ Apps Script ไม่รองรับ CORS จึงอ่านผลตอบกลับไม่ได้ ข้อความ "ส่งคำตอบเรียบร้อย" หมายถึงส่งคำขอออกไปได้ ไม่ได้ยืนยันว่า Sheet บันทึกแล้ว ตอนตั้งค่าครั้งแรกจึงควรทดลองส่งแล้วเปิด Sheet ตรวจว่ามีแถวใหม่ขึ้นจริง
- ลิงก์ Web App อยู่ในโค้ดฝั่งหน้าเว็บ ใครเปิดดูซอร์สก็เห็น และส่งข้อมูลเข้าชีตได้ จึงควรตั้ง Sheet เป็นส่วนตัว (ไม่แชร์ลิงก์ของ Sheet) และไม่เหมาะกับข้อมูลที่ต้องป้องกันการปลอมแปลงเข้มงวด

deployments** กดแก้ไข (ไอคอนดินสอ) แล้วเลือก **New version** ไม่เช่นนั้นลิงก์เดิมจะยังรันโค้ดเก่าอยู่

**วิธีดูผลลัพธ์**

เปิด Google Sheet ที่ผูกกับสคริปต์ ชีต `feedback` มีคอลัมน์ดังนี้

| คอลัมน์ | ข้อมูล |
|---|---|
| เวลาที่ส่ง | เวลาที่ Apps Script รับคำตอบ |
| ผู้ตอบ | รหัส/ชื่อผู้ตอบ (หรือ "ไม่ระบุ") |
| ใช้งานมานาน | ระยะเวลาที่ได้ใช้งานเว็บ |
| คะแนนรายข้อ | JSON ของคะแนน 1–5 แต่ละข้อ เช่น `{"priority":4,"forget":5,...}` |
| ช่วยแก้ปัญหา % | ค่าจากแถบเลื่อน 0–100 |
| NPS | คะแนนแนะนำต่อ 0–10 |
| ฟีเจอร์ที่ชอบ | ฟีเจอร์ที่เลือก คั่นด้วยจุลภาค |
| ปัญหา / ข้อเสนอแนะ | ข้อความที่ผู้ตอบพิมพ์ |

ข้อมูลที่หน้าเว็บส่งไปมีโครงสร้างประมาณนี้:

```json
{
  "id": "1732170123456-ab12cd",
  "submittedAt": "2026-09-21T09:15:20.000Z",
  "respondent": "P01",
  "duration": "1-3 วัน",
  "scores": { "priority": 4, "forget": 5, "plan": 4, "focus": 3, "insight": 4, "usable": 5 },
  "solveScore": 75,
  "nps": 8,
  "features": ["เมทริกซ์จัดลำดับงาน", "ปฏิทินความคืบหน้า"],
  "problem": "หาเมนูไม่เจอตอนแรก",
  "suggestion": "อยากให้มีแจ้งเตือนทาง LINE ด้วย"
}
```

ส่งออกเป็น CSV/Excel ได้จากเมนู **File → Download** ของ Google Sheets เพื่อสรุปผล (ค่าเฉลี่ยรายข้อ, NPS, ความถี่ของฟีเจอร์ที่ถูกเลือก ฯลฯ) นอกเว็บแอปนี้

> ถ้าอยากเปลี่ยนไปใช้ฐานข้อมูลอื่น (เช่น Firebase, Supabase) แก้เฉพาะฟังก์ชัน `sendFeedbackToServer` และค่า `FEEDBACK_URL` ใน `script.js` ส่วนอื่นของหน้าเว็บไม่ต้องแก้

### อนุญาตสิทธิ์เบราว์เซอร์

- เมื่อเพิ่มรายการเตือนครั้งแรก เบราว์เซอร์จะขอสิทธิ์ **Notification** กดอนุญาตเพื่อให้ระบบแจ้งเตือนได้ตรงเวลา
- ถ้าเลือกเตือนแบบตามสถานที่ เบราว์เซอร์จะขอสิทธิ์ **Location** เพิ่มด้วย
- เปิดแท็บนี้ค้างไว้เพื่อให้ระบบตรวจเวลาและตำแหน่งได้ต่อเนื่อง

ข้อมูลการใช้งานหลัก (งาน ปฏิทิน การจับเวลา เป้าหมาย การเตือน) เก็บใน `localStorage` ของเบราว์เซอร์แต่ละเครื่อง ไม่มีการส่งออกไปที่ไหน ยกเว้นแบบประเมินที่ส่งไป Google Sheet เมื่อผู้ใช้กดส่ง

| Key | ข้อมูล |
|---|---|
| `eisenhower_tasks_deadline` | งานในเมทริกซ์ (ชื่อ คำอธิบาย กำหนดส่ง ความคืบหน้า) |
| `focus_sessions` | ประวัติการจับเวลากิจกรรมทั้งหมด |
| `user_goals` | เป้าหมายที่ตั้งไว้ |
| `quick_reminders` | เรื่องเล็กๆ ที่ตั้งเตือนไว้ |
| `feedback_pending_queue` | คำตอบแบบประเมินที่ส่งขึ้น Google Sheet ไม่สำเร็จ (เช่น ออฟไลน์) เก็บรอส่งซ้ำชั่วคราวเท่านั้น (ไม่ใช่ที่เก็บถาวร) |

ข้อมูลจะหายถ้าล้าง cache/localStorage ของเบราว์เซอร์ หรือใช้งานในโหมด Incognito แล้วปิดหน้าต่าง

**คำตอบแบบประเมินไม่ได้เก็บแบบถาวรใน localStorage** — ที่เก็บถาวรจริงคือ **Google Sheet** ที่ผูกกับ Apps Script
ผู้ที่เคยใช้เวอร์ชันก่อนหน้าไม่ต้องทำอะไร ระบบจะเติมฟิลด์ใหม่ (คำอธิบาย ความคืบหน้า) ให้งานเดิมอัตโนมัติเมื่อเปิดครั้งแรก
