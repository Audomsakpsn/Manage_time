# ⏳ Eisenhower Life Manager

เว็บแอปจัดการงานและชีวิตประจำวัน สร้างจาก Eisenhower Matrix พร้อมปฏิทินความคืบหน้า, ตัวจับเวลากิจกรรม, ระบบเป้าหมายแบบมีระดับสี, สถิติแนวโน้ม และการเตือนความจำตามเวลา/สถานที่

ตัวแอปหลักทำงานบนเบราว์เซอร์ล้วนๆ ข้อมูลงาน ปฏิทิน การจับเวลา เป้าหมาย และการเตือนความจำ ถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์ผู้ใช้เอง ไม่ต้องมีเซิร์ฟเวอร์

ส่วนแบบประเมิน (Feedback) สำหรับเก็บผลสะท้อนจากกลุ่มทดลองเป็นข้อยกเว้น: ต้องรันไฟล์ `server.js` ที่แถมมาด้วย เพื่อให้คำตอบทุกชุดถูกบันทึกลงไฟล์ `feedback.json` ซึ่งทำหน้าที่เป็นฐานข้อมูลกลางของระบบ ดูวิธีรันได้ในหัวข้อ "วิธีติดตั้งและรัน" ด้านล่าง

## ✨ ฟีเจอร์

### 🧭 วันนี้
สรุปภาพรวมของวัน — งานที่เลยกำหนด, งานที่ครบกำหนดวันนี้, เรื่องเล็กๆ ที่ต้องเตือน, ตัวเลขสรุป (เวลาโฟกัสวันนี้เทียบเมื่อวาน, งานที่ปิดได้สัปดาห์นี้, จำนวนวันที่ทำต่อเนื่อง), แถบความคืบหน้าของทุกเป้าหมาย และไทม์ไลน์รวมทุกอย่างเรียงตามเวลา

### 📊 งานทั้งหมด (Eisenhower Matrix)
เพิ่มงานพร้อม **คำอธิบาย** และกำหนดส่ง ระบบจะจัดเข้า 4 ช่องตามความสำคัญ/ความเร่งด่วน

- 🚨 Q1 ทำทันที
- 📅 Q2 วางแผนทำ
- 👥 Q3 ให้คนอื่นทำแทน
- 🗑️ Q4 ทำท้ายสุด

คลิกที่ชื่องานเพื่อเปิดหน้ารายละเอียด แก้คำอธิบาย ปรับเปอร์เซ็นต์ความคืบหน้าด้วยแถบเลื่อน ดูเวลาที่ใช้ไปกับงานนั้น หรือกดจับเวลาทำงานนั้นได้ทันที ถ้าพิมพ์ชื่องานผิด กดปุ่ม ✎ บนการ์ดเพื่อเปิดหน้ารายละเอียดพร้อมโฟกัสไปที่ช่องชื่อทันที แก้แล้วกด "บันทึกชื่อ"

งานที่ทำเสร็จแล้วจะถูกเลื่อนลงไปอยู่ล่างสุดของช่องโดยอัตโนมัติ ส่วนงานที่ยังค้างเรียงตามกำหนดส่งจากใกล้ที่สุดไปไกลที่สุด ทำให้งานที่ต้องสนใจอยู่บนสุดเสมอ

### 📅 ปฏิทิน
ดูงานแบบรายเดือน แต่ละวันแสดง **แถบสีความคืบหน้าเฉลี่ย** ของงานที่ครบกำหนดวันนั้น จุดสีบอกควอดแรนต์ของงาน และจุดน้ำเงินบอกวันที่มีการจับเวลา คลิกวันไหนก็เห็นสรุปและรายการงานของวันนั้น พร้อมปุ่มเพิ่มงานให้ตรงวัน

### ⏱️ จับเวลากิจกรรม
นาฬิกาจับเวลาแยกต่างหากสำหรับกิจกรรมอย่างอ่านหนังสือ ทำงาน เรียน หรือออกกำลังกาย เลือกกิจกรรม ผูกกับงานในเมทริกซ์ได้ (ถ้าต้องการ) ใส่บันทึกสั้นๆ แล้วกดเริ่ม/จบ เวลาจะถูกเก็บเข้าสถิติและนับเข้าเป้าหมายอัตโนมัติ มีปุ่มบันทึกเวลาย้อนหลังเผื่อลืมกดจับเวลา

### 🎯 เป้าหมาย
ตั้งเป้าเวลาต่อวัน/สัปดาห์/เดือน สำหรับแต่ละกิจกรรม แล้วระบบจะนับความคืบหน้าจากการจับเวลาให้เอง แต่ละเป้าหมายจะเลื่อน **ระดับตามสี** ตามเปอร์เซ็นต์ที่ทำได้

| ระดับ | ช่วง | สี |
|---|---|---|
| ยังไม่เริ่ม | 0% | เทา |
| เริ่มแล้ว | 1–39% | เหลือง |
| ไปได้ครึ่งทาง | 40–69% | ฟ้า |
| ใกล้เสร็จ | 70–99% | น้ำเงิน |
| สำเร็จแล้ว | 100% | เขียว |

ระดับสีชุดเดียวกันนี้ใช้กับความคืบหน้าของงานในเมทริกซ์และในปฏิทินด้วย

### 📈 สถิติ
- กราฟแท่งแนวโน้มเวลาโฟกัสรายวัน (เลือกดู 7 / 14 / 30 วัน) พร้อมเส้นค่าเฉลี่ยเคลื่อนที่ 3 วันเพื่อดูทิศทาง
- เวลารวมและเฉลี่ยต่อวัน เทียบกับ 7 วันก่อนหน้าว่าเพิ่มขึ้นหรือลดลง
- อัตราส่งงานทันกำหนด
- ความคืบหน้าเฉลี่ยของงานที่ยังค้าง
- จำนวนงานที่ปิดได้ในแต่ละสัปดาห์ย้อนหลัง 6 สัปดาห์
- สัดส่วนเวลาแยกตามกิจกรรม

### 🔔 เตือนความจำ
บันทึกเรื่องเล็กๆ เช่น กินยา โทรกลับแฟน ทิ้งขยะ พร้อมตั้งเตือนได้ 3 แบบ

- ⏰ ทุกวันตามเวลาที่กำหนด
- 📆 ครั้งเดียวตามวัน-เวลาที่กำหนด
- 📍 เมื่อไปถึงสถานที่ที่กำหนด (กำหนดรัศมีเป็นเมตรได้)

### ⏲️ Pomodoro
ตัวนับถอยหลัง 25 นาทีที่หัวเว็บ เริ่ม/พัก/รีเซ็ตได้ตลอดเวลาไม่ว่าจะอยู่แท็บไหน

## 🗂️ โครงสร้างไฟล์

```
.
├── index.html      # โครงหน้าเว็บและ layout ทั้งหมด
├── style.css       # ดีไซน์และธีมของเว็บแอป
├── script.js       # ลอจิกทั้งหมด (งาน ปฏิทิน จับเวลา เป้าหมาย สถิติ การเตือน แบบประเมิน)
├── server.js       # เซิร์ฟเวอร์เล็กๆ สำหรับเสิร์ฟเว็บ + บันทึก Feedback ลงฐานข้อมูล
├── feedback.json   # ฐานข้อมูล Feedback (server.js สร้าง/แก้ไขไฟล์นี้ให้อัตโนมัติ)
└── README.md
```

ไฟล์ทั้งหมดต้องอยู่ในโฟลเดอร์เดียวกัน เพราะ `index.html` อ้างอิง `style.css` และ `script.js` ด้วย relative path และ `server.js` อ้างอิง `feedback.json` ด้วย path ในโฟลเดอร์เดียวกันเช่นกัน

## 🛠️ Tech Stack

- HTML5 + CSS ที่เขียนเอง ไม่พึ่ง framework และไม่ต้อง build
- JavaScript (Vanilla, ไม่มี framework และไม่มี build step)
- กราฟสถิติวาดด้วย SVG ที่เขียนเองในโค้ด ไม่ใช้ไลบรารีภายนอก
- Web APIs: `localStorage`, `Notification`, `Geolocation`, `fetch`
- ฟอนต์ [Prompt](https://fonts.google.com/specimen/Prompt) จาก Google Fonts
- **server.js**: เซิร์ฟเวอร์ฝั่งหลังบ้านที่เขียนด้วย Node.js ล้วน (ใช้แค่โมดูลมาตรฐาน `http`, `fs`, `path`, `url` ไม่ต้อง `npm install` ใดๆ) ทำหน้าที่เสิร์ฟไฟล์เว็บและรับ-บันทึก Feedback

### 🗳️ แบบประเมิน (เก็บ Feedback จากกลุ่มทดลองลงฐานข้อมูล)

หน้าสำหรับเก็บผลสะท้อนหลังการใช้งาน ออกแบบมาให้ใช้กับการทดลองในรายวิชาโดยเฉพาะ **หน้านี้แสดงเฉพาะฟอร์ม ไม่มีการแสดงผลสรุปหรือคำตอบของใครกลับบนหน้าเว็บเลย** — ส่งแล้วข้อมูลจะไปอยู่ในฐานข้อมูลของระบบทันที ผู้ทดลองใช้จะเห็นแค่ข้อความ "ส่งคำตอบเรียบร้อย"

**แบบประเมิน** ประกอบด้วย

- ข้อมูลผู้ตอบ (รหัส/ชื่อ และระยะเวลาที่ได้ใช้งาน)
- คำถามมาตรวัด 1–5 จำนวน 6 ข้อ ครอบคลุมการจัดลำดับงาน การลืมงาน การวางแผนล่วงหน้า การโฟกัส การเห็นพฤติกรรมตัวเอง และความง่ายในการใช้งาน
- แถบเลื่อน 0–100% ว่าโดยรวมเว็บนี้ช่วยแก้ปัญหาได้มากแค่ไหน
- คะแนนแนะนำต่อ 0–10 (ใช้คำนวณ NPS ได้ภายหลัง)
- ฟีเจอร์ที่ช่วยได้มากที่สุด (เลือกได้หลายข้อ)
- ปัญหาที่เจอ และข้อเสนอแนะแบบข้อความ

แก้ไขชุดคำถามได้ที่ตัวแปร `LIKERT_QUESTIONS` และ `FEATURE_OPTIONS` ตอนต้นส่วน FEEDBACK ใน `script.js` เพิ่มหรือลดข้อได้ตามสมมติฐานการทดลอง

## 🗄️ ฐานข้อมูล Feedback (server.js + feedback.json)

เมื่อผู้ทดลองใช้กด **"ส่งแบบประเมิน"** หน้าเว็บจะส่งคำตอบแบบ `POST` ไปที่ `/api/feedback` ซึ่งเป็นส่วนหนึ่งของ `server.js` เซิร์ฟเวอร์จะเขียนคำตอบต่อท้าย **`feedback.json`** ทันที ไฟล์นี้คือฐานข้อมูลของระบบตามที่โจทย์ของรายวิชาต้องการ

**คุณสมบัติสำคัญ**

- คำตอบไม่ถูกแสดงกลับบนหน้าเว็บที่ไหนเลย ไม่มีหน้าสรุปผล ไม่มีรายการคำตอบให้ผู้ทดลองใช้เห็น
- `feedback.json` ถูกล็อกไม่ให้เปิดผ่านเบราว์เซอร์ (ไปที่ `http://localhost:8000/feedback.json` จะได้ 403) ต้องเปิดจากเครื่องโดยตรงเท่านั้น
- ถ้าส่งไม่สำเร็จ (เช่น ลืมรัน `node server.js`) ระบบจะเก็บคำตอบไว้ชั่วคราวใน `localStorage` ของเครื่องนั้น แล้วพยายามส่งซ้ำให้อัตโนมัติทุก 2 นาที โดยไม่แสดงผลใดๆ บนหน้าเว็บเช่นกัน

**วิธีดูผลลัพธ์**

เปิดไฟล์ `feedback.json` ด้วยโปรแกรมข้อความ หรือดูจากเทอร์มินัลก็ได้:

```bash
cat feedback.json
```

แต่ละรายการมีโครงสร้างประมาณนี้:

```json
{
  "id": "1732170123456-ab12cd",
  "receivedAt": "2026-09-21T09:15:23.456Z",
  "submittedAt": "2026-09-21T09:15:20.000Z",
  "respondent": "P01",
  "duration": "1-3 วัน",
  "scores": { "priority": 4, "forget": 5, "plan": 4, "focus": 3, "insight": 4, "usable": 5 },
  "solveScore": 75,
  "nps": 8,
  "features": ["เมทริกซ์จัดลำดับงาน", "ปฏิทินความคืบหน้า"],
  "problem": "หาเมนูไม่เจอตอนแรก",
  "suggestion": "อยากให้มีแจ้งเตือนทาง LINE ด้วย"
}
```

เนื่องจากเป็นไฟล์ JSON ธรรมดา สามารถนำเข้า Excel/Google Sheets หรือเขียนสคริปต์ Python/Node เพื่อสรุปผล (ค่าเฉลี่ยรายข้อ, NPS, ความถี่ของฟีเจอร์ที่ถูกเลือก ฯลฯ) ได้ตามต้องการ นอกเว็บแอปนี้

> ถ้าอยากเปลี่ยนไปใช้ฐานข้อมูลอื่น (เช่น SQLite, MongoDB, Google Sheets) แก้เฉพาะฟังก์ชัน `handleFeedbackPost` ใน `server.js` ส่วนหน้าเว็บ (`script.js`) ไม่ต้องแก้อะไรเลย เพราะยังคง POST ข้อมูล JSON ไปที่ `/api/feedback` เหมือนเดิม

### อนุญาตสิทธิ์เบราว์เซอร์

- เมื่อเพิ่มรายการเตือนครั้งแรก เบราว์เซอร์จะขอสิทธิ์ **Notification** กดอนุญาตเพื่อให้ระบบแจ้งเตือนได้ตรงเวลา
- ถ้าเลือกเตือนแบบตามสถานที่ เบราว์เซอร์จะขอสิทธิ์ **Location** เพิ่มด้วย
- เปิดแท็บนี้ค้างไว้เพื่อให้ระบบตรวจเวลาและตำแหน่งได้ต่อเนื่อง

## 💾 การเก็บข้อมูล

ข้อมูลการใช้งานหลัก (งาน ปฏิทิน การจับเวลา เป้าหมาย การเตือน) เก็บใน `localStorage` ของเบราว์เซอร์แต่ละเครื่อง ไม่มีการส่งออกไปที่เซิร์ฟเวอร์

| Key | ข้อมูล |
|---|---|
| `eisenhower_tasks_deadline` | งานในเมทริกซ์ (ชื่อ คำอธิบาย กำหนดส่ง ความคืบหน้า) |
| `focus_sessions` | ประวัติการจับเวลากิจกรรมทั้งหมด |
| `user_goals` | เป้าหมายที่ตั้งไว้ |
| `quick_reminders` | เรื่องเล็กๆ ที่ตั้งเตือนไว้ |
| `feedback_pending_queue` | คำตอบแบบประเมินที่ส่งขึ้นฐานข้อมูลไม่สำเร็จ เก็บรอส่งซ้ำชั่วคราวเท่านั้น (ไม่ใช่ที่เก็บถาวร) |

ข้อมูลจะหายถ้าล้าง cache/localStorage ของเบราว์เซอร์ หรือใช้งานในโหมด Incognito แล้วปิดหน้าต่าง

**คำตอบแบบประเมินไม่ได้เก็บแบบถาวรใน localStorage** — ที่เก็บถาวรจริงคือไฟล์ **`feedback.json`** บนเครื่องที่รัน `node server.js` (ดูรายละเอียดในหัวข้อ "ฐานข้อมูล Feedback" ด้านบน) ดังนั้นอย่าลืมสำรอง/คัดลอกไฟล์ `feedback.json` เก็บไว้หลังเก็บข้อมูลจากกลุ่มทดลองเสร็จ

ผู้ที่เคยใช้เวอร์ชันก่อนหน้าไม่ต้องทำอะไร ระบบจะเติมฟิลด์ใหม่ (คำอธิบาย ความคืบหน้า) ให้งานเดิมอัตโนมัติเมื่อเปิดครั้งแรก
