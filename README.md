# ⏳ Eisenhower Life Manager + Deadline

เว็บแอปจัดการงานและชีวิตประจำวัน สร้างจาก Eisenhower Matrix (จัดลำดับความสำคัญ/ความเร่งด่วน) พร้อมปฏิทิน, แดชบอร์ดสรุปแผนวันนี้, ระบบเตือนความจำเรื่องเล็กๆ (ตามเวลา/สถานที่) และตัวจับเวลาโฟกัสแบบ Pomodoro

ทำงานบนเบราว์เซอร์ล้วนๆ ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล ข้อมูลทั้งหมดถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์ผู้ใช้เอง

---

## ✨ ฟีเจอร์

- **🧭 วันนี้ / แผนล่วงหน้า** — แดชบอร์ดสรุปงานที่เลยกำหนด, งานที่ครบกำหนดวันนี้, เรื่องเล็กๆ ที่ต้องเตือน และไทม์ไลน์รวมทุกอย่างเรียงตามเวลา
- **📊 เมทริกซ์งาน (Eisenhower Matrix)** — เพิ่มงานพร้อมกำหนดส่ง (deadline) แล้วระบบจะจัดเข้า 4 ควอดแรนต์ตามความสำคัญ/ความเร่งด่วนให้อัตโนมัติ
  - 🚨 Q1: ทำทันที
  - 📅 Q2: วางแผนทำ
  - 👥 Q3: ให้คนอื่นทำแทน
  - 🗑️ Q4: ตัดทิ้ง/เลิกทำ
- **📅 ปฏิทิน** — ดูงานทั้งหมดแบบรายเดือน คลิกวันไหนก็เห็นงานของวันนั้น และเพิ่มงานใหม่ให้ตรงวันได้ทันที
- **🔔 เรื่องเล็กๆ ประจำวัน** — บันทึกสิ่งที่ต้องทำเล็กๆ น้อยๆ เช่น กินยา, ตื่นนอน, ทิ้งขยะ พร้อมตั้งเตือนได้ 3 แบบ:
  - ⏰ เตือนทุกวันตามเวลาที่กำหนด
  - 📆 เตือนครั้งเดียวตามวัน-เวลาที่กำหนด
  - 📍 เตือนเมื่อไปถึงสถานที่ที่กำหนด (ใช้ Geolocation ของเบราว์เซอร์)
- **⏱️ Pomodoro Timer** — ตัวจับเวลาโฟกัส 25 นาที เริ่ม/พัก/รีเซ็ตได้จากหัวเว็บ

## 🗂️ โครงสร้างไฟล์

```
.
├── index.html   # โครงหน้าเว็บและ layout ทั้งหมด
├── style.css    # พื้นหลังตกแต่งหน้าเว็บ
└── script.js    # ลอจิกทั้งหมดของแอป (state, localStorage, ปฏิทิน, การเตือน, Pomodoro)
```

ไฟล์ทั้งสามต้องอยู่ในโฟลเดอร์เดียวกัน เพราะ `index.html` อ้างอิงอีกสองไฟล์ด้วย relative path

---

## 🛠️ Tech Stack

- HTML5 + [Tailwind CSS](https://tailwindcss.com/) (โหลดผ่าน CDN)
- JavaScript (Vanilla, ไม่มี framework/build step)
- Web APIs: `localStorage`, `Notification`, `Geolocation`
- ฟอนต์ [Prompt](https://fonts.google.com/specimen/Prompt) จาก Google Fonts
